================================================================================
CSRF RESPONSE INDICATORS (What to Look For)
================================================================================

Missing CSRF token – No protection
CSRF token not validated – Token present but ignored
Token in URL – Weak protection (leaks via referer)
No SameSite cookie – Vulnerable to cross-origin requests
GET request changes state – Very dangerous
Token predictable – Sequential or timestamp-based

================================================================================
CSRF PROTECTION BYPASS INDICATORS
================================================================================

Token removed – Request still works
Token replaced with blank – Works with blank token
Token reused – Same token works across sessions
Header removed – X-CSRF-Token not required
Referer not checked – No referer validation
Origin not checked – No origin validation
