import httpx

async def send_request(session, url, data):

async def race_test(url, data, concurrency=20):
    async with httpx.AsyncClient() as session:
        tasks = [send_request(session, url, data) for _ in range(concurrency)]
        responses = await asyncio.gather(*tasks)
        return responses

================================================================================
RACE CONDITION RESPONSE INDICATORS (What to Look For)
================================================================================

200 OK – Request succeeded (multiple successes may indicate race)
201 Created – Resource created (duplicate creations indicate race)
202 Accepted – Request queued
409 Conflict – Conflict error (protected)
429 Too Many Requests – Rate limited (protected)
403 Forbidden – Access denied (protected)
Duplicate entries – Multiple records created
Balance went negative – Withdrawal race confirmed
